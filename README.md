# TimeTable

Настольное приложение для составления школьского расписания: классы,
учителя, предметы, кабинеты, ограничения, генерация и ручная правка.

## Возможности

- генерация расписания и отчёт о конфликтах;
- перенос и обмен уроков перетаскиванием (drag & drop) или кликом по
  ячейкам: целевая ячейка подсвечивается во время перетаскивания,
  изменение отображается мгновенно, Esc отменяет перетаскивание;
  используется pointer capture, поэтому drag работает стабильно
  в WebView2 и WKWebView (в v1.8.0 исправлена причина «зависания» сетки —
  ячейки не пересчитывались после изменения расписания);
- печать по режимам: плакат «вся школа» на одном листе либо по одной
  странице на класс / учителя / кабинет — печать использует те же
  настройки, что и экспорт PDF (формат бумаги, ориентация, учителя,
  кабинеты, будни, ч/б);
- экспорт расписания в PDF и CSV;
- PDF генерируется на стороне Go (gopdf + встроенный шрифт DejaVu Sans
  с поддержкой кириллицы) — это надёжнее, чем jsPDF в WebKit/Wails;
  в v1.8.0: шапка уроков со временем звонков на плакате, полные границы
  сетки, перенос текста по фактической ширине, вертикальное
  центрирование, адаптивный размер шрифта, номера страниц («стр. 3 из 35»)
  и дата печати в футере;
- экспорт полной резервной копии в JSON и безопасное восстановление;
- восстановление сохраняет настройки, подгруппы, ограничения и готовое
  расписание, при этом не затирает другую школу при совпадении ID.

## Разработка и проверка

```sh
cd frontend && npm ci && npm run check && npm run build
GOCACHE=/tmp/timetable-go-cache go test ./...
```

Для запуска в режиме разработки используйте `wails dev`; для production-сборки
— `wails build`.

## Версия на Fyne

Альтернативный нативный интерфейс находится в `cmd/fyne`. Для больших расписаний
собирайте его с OR-Tools CP-SAT: исходники решателя сохранены в
`internal/solver/ortools_csat.go` и `internal/solver/ortools_csat_windows.go`.
Сборка без `-tags ortools` включает только стандартный Go-решатель.

```sh
# Linux: подготовить OR-Tools (один раз на машине)
./scripts/build_ortools.sh

# Запуск с CP-SAT
LD_LIBRARY_PATH="$PWD/third_party/ortools/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}" go run -tags ortools ./cmd/fyne

# Собрать приложение с CP-SAT и положить рядом динамическую библиотеку
go build -tags ortools -o timetable-fyne ./cmd/fyne
cp -L third_party/ortools/lib/libortools.so* .
```

На Windows используйте `scripts/build_ortools_windows.sh`, соберите с
`-tags ortools` и разместите `ortools_csat.dll` рядом с приложением. В разделе
«Генерация» Fyne показывает, включён ли CP-SAT в запущенной сборке.

Приложение использует общую с основной версией SQLite-схему, генератор, модели
и PDF-рендерер. База хранится рядом с исполняемым файлом, если эта папка
доступна для записи; иначе — в каталоге пользовательских настроек приложения.
